# Motor Runtime Contract

Contract version: `1`

## 책임

- 프로젝트 파일은 편집 대상이다.
- RuntimeSession은 Motor Manager가 실행하는 불변 설정이다.
- `motion_system`은 모터 통신과 제어의 단일 통로다.
- Web Bridge는 프로젝트 선택, RuntimeSession 적용, 서비스 재시작과
  실행 결과 검증만 조정한다.

## RuntimeSession

- 설정 적용 시 유효성 검사를 통과한 모터 설정을 내용 SHA-256 기반의
  프로젝트별 `runtime/sessions/` 파일로 생성한다.
- 실행 중인 RuntimeSession 파일은 같은 프로젝트의 재편집·재적용으로
  덮어쓰지 않는다.
- 런타임 상태에는 프로젝트 ID, 세션 ID, 프로젝트 내부 상대 경로,
  SHA-256과 프로젝트 세대를 기록한다.
- Motor Manager 시작 전에 상대 경로가 현재 프로젝트의
  `runtime/sessions/` 내부인지와 SHA-256 일치를 다시 검증한다.
- 새 적용이 실패하면 이전 RuntimeSession을 그대로 복원한다.

## 작업 상태

- 설정 적용, 모터 재시작과 물리 검색은 동시에 하나만 실행한다.
- 상태 파일 변경은 스레드 잠금과 프로세스 파일 잠금을 함께 사용한다.
- 제한시간을 초과한 작업의 복구·재시작은 한 번만 실행한다.
- 모터 설정 적용 완료는 Motor Manager 설정 경로, 서비스 실행 세대,
  새 모터 피드백과 설정 대상 축 상태로 판정한다.
- 모션축 설정이 없다는 이유로 모터 설정 적용 자체를 실패 처리하지 않는다.
- 모션 제어 허용은 모터 설정 적용과 별도로 전체 실행 컨텍스트가 준비된
  이후에만 부여한다.

## 프로젝트 격리

- 편집 프로젝트와 실행 프로젝트를 별도로 표시한다.
- 다른 프로젝트의 RuntimeSession, 검색 결과 또는 비동기 작업 결과를
  현재 프로젝트의 대체값으로 사용하지 않는다.
- 프로젝트 전환은 실행 중 Motor Manager의 RuntimeSession을 임의로
  변경하지 않는다.
