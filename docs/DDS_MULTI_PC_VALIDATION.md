# DDS 멀티 PC 실물 검증 절차

## 판정 원칙

- 대상 · 실제 PC 2대부터 시작, 완료 후 최대 8대로 확대
- 코드 검증·실행 검증·실물 검증 결과를 분리 기록
- 모터를 연결하지 않은 단계에서 실패하면 다음 단계로 진행하지 않음
- 각 PC의 로그에 `pc_id`, `execution_id`, `cycle_number`, 요청시각,
  실제 소프트웨어 트리거시각, 오류를 기록

## 1. 공통 준비

1. 두 PC에 같은 커밋을 배포하고 전체 빌드를 완료한다.
2. `motion-coordination.service`의 `ROS_LOCALHOST_ONLY=0`을 확인한다.
3. `127.0.0.1:8011`만 로컬 API로 대기하고 외부 구형 연동 포트가 없는지 확인한다.
4. 방화벽에서 ROS 2 DDS가 사용하는 UDP 통신을 같은 Wi-Fi 구간에 허용한다.
5. 각 PC 웹 `DDS 그룹 연동`에서 서로 다른 `이 PC ID`, 같은 `그룹 ID`, 같은
   `DDS Domain ID`를 저장한다.
6. 두 PC 모두 `DDS 연동 노드 연결됨`인지 확인한 뒤 `그룹 참가`를 누른다.

## 2. 모터 없는 검증

1. 연결 · 두 화면에 참가 PC 2대가 표시되는지 확인한다.
2. 격리 · 다른 그룹 ID 또는 Domain ID의 시험 노드가 목록에 나타나지 않는지 확인한다.
3. 중복 · 같은 명령 ID를 재전달해 로컬 처리가 한 번뿐인지 로그로 확인한다.
4. 단절 · 한 PC 연동 프로세스를 종료하고 1.5초 경고·3초 단절 판정을 확인한다.
5. 재시작 · 실행 참가 목록이 고정된 상태에서 한 PC를 재시작하면 전체 정지되는지 확인한다.
6. 복구 · 두 PC에서 다시 `그룹 참가`를 누른 뒤 상태가 정상 복구되는지 확인한다.
7. 동시 시작 · 두 PC에서 동시에 `그룹 모션 시작`을 누르고 하나의 `execution_id`만 남는지 확인한다.
8. 지연 차단 · 참가 PC 한 대가 `warning`이면 정상 PC만으로 축소 실행되지 않는지 확인한다.
9. 명시적 나가기 · `그룹 나가기`가 다른 PC 화면에 즉시 반영되는지 확인한다.
10. 중복 ID · 두 PC에 같은 `이 PC ID`를 설정하면 `DUPLICATE_PC_ID`로 참가·실행이 차단되는지 확인한다.
11. 참가 목록 불일치 · 한 PC만 알고 있는 참가 PC가 있으면 `PREPARE`에서 전체 실행이 취소되는지 확인한다.
12. 로컬 상태 단절 · 그룹 실행 중 Web Bridge 상태 응답을 500ms 이상 중단하고 로컬 정지 시도·전체 `STOP_NOW`·재실행 차단을 확인한다.
13. 명령 경합 · 로컬 `START_AT` HTTP 처리가 반환되지 않은 상태에서 같은 실행의 `STOP_NOW`를 전달하고, `motion_supervisor` 안전 정지 명령이 우선 전달되며 늦은 시작이 폐기되는지 확인한다.

## 3. 모터 연결·초기화

1. 각 PC에서 서로 독립적인 프로젝트·모션·모션축 설정을 선택한다.
2. 기존 단독 `1회 모션`과 `자동 반복`을 각 PC에서 별도로 확인한다.
3. 자동 반복을 정지하고 두 PC를 그룹에 참가시킨다.
4. `그룹 모션 시작` 후 두 PC의 실행 준비가 모두 통과하는지 확인한다.
5. 두 PC 초기위치 이동 완료 후에만 전체 `ARMED`가 되는지 확인한다.
6. 초기화 트리거 편차가 20ms 이내인지 로그로 판정한다.

## 4. 단일·연속 회차

1. 첫 `START_AT`당 각 PC의 `motion_started_monotonic`이 한 번만 기록되는지 확인한다.
2. 예약시각이 아닌 실제 콜백 `motion_started_monotonic`의 `max-min`이 20ms 이내인지 판정한다.
3. 모션시간이 서로 다른 파일을 사용해 먼저 끝난 PC만 `CYCLE_READY`로 대기하는지 확인한다.
4. 늦은 PC의 `CYCLE_READY` 전에는 다음 `START_AT`이 없는지 확인한다.
5. 전체 `CYCLE_READY` 후 다음 회차가 각 PC에서 정확히 한 번 실행되는지 확인한다.
6. 장시간 실행에서 매 회차 시작 편차와 DDS 추정 불확실성을 기록한다.

## 5. 정지·오류

1. 어느 PC에서든 `현재 회차 후 정지` · 현재 모션 완료·회차 사이 준비 생략·다음 시작 없음.
2. 어느 PC에서든 `전체 즉시 정지` · 요청 PC 로컬 정지가 DDS 전파보다 먼저 기록·두 PC 모션 즉시 정지.
3. 1등급 오류 · 해당 축 차단·현재 회차 완료·다음 회차 없음.
4. 2등급 오류 · 두 PC 전체 즉시 정지.
5. 3등급 오류 · 두 PC 전체 즉시 정지·오류 PC의 재시작 전 모터 제어 차단.
6. 시작 예약 ACK 누락·DDS 트리거 동기화 불량 · 일부 PC만 시작하지 않고 전체 시작 전 취소.
7. 모션 시작 트리거 20ms 초과 · 전체 즉시 정지·`GROUP_TRIGGER_SPREAD_EXCEEDED`·추가 실행 차단.
8. 사용자 오류 확인 · 전체 PC 오류 표시 해제·그룹 실행 정상 복구.
9. `START_AT` 수락 후 한 PC의 `motion_started` 보고 누락 · 1초 후 전체 즉시 정지·재실행 차단.
10. 시작 예약시각 경과 후 ACK 누락 · `CANCEL_BEFORE_START`가 아니라 전체 즉시 정지.
