## 1. 시작하기

**이 문서를 웹에서 보기** : `운영` → `사용법` · 설치법도 같은 자리에 있습니다

**주소** : `http://localhost:8000`
**다른 PC 에서** : `http://<그 PC 주소>:8000` · 예 `http://172.16.21.10:8000`

### 화면 구성

**묶음** : 4개 · 그 아래에 탭

| 묶음 | 탭 |
|---|---|
| 운영 | 실시간 모니터링 · 서보 에러 관리 · 로그 · PC 성능 · 터미널 |
| 프로젝트·장비 | 시스템 정보 · 프로젝트 관리 · 모터 관리 |
| 모션 제작 | 모션축 설정 · MIDI 입력 설정 · 모션 스튜디오 |
| 실행·시험 | 동작 테스트 · 모션 실행 · PC 연동 설정 |

**맨 위 오른쪽** : `📅 모션 스케줄` 버튼 · 스케줄러 상태 딱지

📷 *(캡처: 화면 맨 위 · 묶음 4개와 탭)*

### 딱지 색

| 색 | 뜻 |
|---|---|
| 🟢 초록 | 정상 · 시각이 되면 돎 |
| 🟡 노랑 | 돌아야 하는데 못 돎 |
| 🔴 빨강 | 계속 못 돎 |
| ⚫ 회색 | 스케줄이 손대지 않음 |

**이유 보기** : 딱지에 마우스 올리기

### 화면 맨 위 버튼

| 버튼 | 무엇 |
|---|---|
| `전체 동작 정지` | 모든 모터 즉시 정지 · 서보는 켜진 채 |
| `프로그램 재시작` | 프로그램 전체 재시작 · 확인 창 뜸 |

**위치** : 어느 화면에서든 늘 보임
**주의** : 스케줄 모드에서 정지하면 최대 1분 뒤 다시 시작 → 계속 멈추려면 [9장](#9-스케줄-걸기) 수동 모드 먼저

## 3. 모터 등록하기

**위치** : `프로젝트·장비` → `모터 관리`
**하는 일** : 연결된 모터를 찾아 이 프로젝트에 등록
**확인** : 표의 축이 정상 · 위쪽 `현재 실행 장비 상태` 가 맞음

### 순서

```
1) 전체 모터 검색
2) 표에서 줄 선택  →  선택 축 추가
3) (필요하면) 상세 설정 표에서 값 수정
4) 설정 저장  →  장비에 적용 · 모터 재시작
```

### 3-0. 위쪽 영역

| 버튼 | 무엇 |
|---|---|
| `모터 상태 확인` | 장비 상태 다시 읽기 |
| `전체 AC 서보 켜기` · `전체 AC 서보 끄기` | AC 서보 전체에 힘 넣기·빼기 |
| `모터 제어 재시작` | 모터 다루는 부분만 재시작 |
| `설정 불러오기` | 저장된 설정 파일 다시 읽기 |
| `설정 삭제` | 설정 파일을 휴지통으로 · 돌고 있는 장비 설정은 그대로 |

**현재 실행 장비 상태** : 지금 장비에 들어가 있는 설정 · 아래에서 고친 값과 다르면 아직 적용 전

### 3-1. 찾기

**위치** : `1. 장비 검색`

| 버튼 | 언제 |
|---|---|
| `전체 모터 검색` | 보통 이것 |
| `AC Servo 검색` | AC 서보만 |
| `Dynamixel 검색` | 다이나믹셀만 |

📷 *(캡처: 검색 결과가 나온 표)*

**안 나올 때** : [12장](#12-문제가-생겼을-때)

### 3-2. 쓸 축 고르기

**위치** : `2. 검색 결과 확인 및 축 편집`
**방법** : 표에서 줄을 누르고 아래 버튼

| 버튼 | 무엇 |
|---|---|
| `선택 축 추가` | 이 프로젝트에서 쓰겠다고 등록 |
| `모델·운전 프로필 설정` | 모터 종류·운전값 지정 |
| `선택 축 사용상태 변경` | 잠시 안 쓰게 |
| `축 번호 정렬` | 번호를 차례로 |
| `선택 축 삭제` | 등록 취소 |
| `선택 축 검색값 반영` | 검색된 모델·일련번호·연결정보를 덮어쓰기 |
| `EEPROM Alias 변경` | 드라이브에 고유 번호 적기 · 랜선 순서가 바뀌어도 같은 축으로 인식 |

### 3-3. 값 고치기

**위치** : `상세 설정 표` 탭
**고칠 수 없는 항목** : 입력칸이 아니라 글자로만 보임

| 항목 | 무엇 |
|---|---|
| `controller_index` · `name` | 축 번호 · 이름 |
| `lower` · `upper` | 움직일 수 있는 최소·최대 위치 |
| `speed` · `acceleration` · `deceleration` | 속도 · 가감속 |
| `profile_velocity` 등 | 운전 프로필 |

### 3-4. 저장하고 장비에 넣기

**위치** : `3. 저장하고 장비에 적용` · 왼쪽부터

| | 버튼 | 무엇이 되나 |
|---|---|---|
| 1단계 | `설정 저장` | 설정 파일에 적힘 · 모터는 그대로 |
| 2단계 | `장비에 적용 · 모터 재시작` | 실제 모터에 들어감 · 모터가 잠깐 멈췄다 켜짐 |

**주의** : 2단계를 안 누르면 모터는 안 바뀜 · 파일만 바뀜

📷 *(캡처: 3. 저장하고 장비에 적용 · 버튼 두 개)*

## 4. 모션축 잇기

**위치** : `모션 제작` → `모션축 설정`
**하는 일** : 모터축(`축 0`)과 모션 ID(`1-1`)를 맺기
**확인** : `미사용 모터축` 에 남은 축 없음

### 순서

```
1) 1. 설정 파일 선택  →  목록에서 고르거나 「새 매칭 작성」
2) 2. 모션축 편집    →  모터축 행 자동 생성
3) 줄마다 모션 ID ↔ 모터축 맞추기
4) 3. 검증·미리보기·저장
```

📷 *(캡처: 2. 모션축 편집 표 · 모션 ID 와 모터축이 맺어진 상태)*

### 버튼

| 버튼 | 무엇 |
|---|---|
| `목록 새로고침` | 파일 목록 다시 읽기 |
| `새 매칭 작성` | 새 설정 파일 만들기 |
| `모터축 행 자동 생성` | 등록된 모터 수만큼 줄 만들기 |
| `모션 ID 추가` | 줄 하나 추가 |
| `모션 ID 반영` | 스튜디오에서 쓰는 이름 가져오기 |
| `검증·미리보기·저장` | 확인하고 저장 |
| `저장된 내용으로 되돌리기` | 고친 것 취소 |
| `현재 설정 파일 삭제` | 이 매칭 파일 삭제 |

## 5. 모션 만들기

**위치** : `모션 제작` → `모션 스튜디오`
**방법** : MIDI 조작기로 모터를 움직이며 녹화

### 5-0. MIDI 준비

**위치** : `모션 제작` → `MIDI 입력 설정`
**언제** : 녹화 전에 한 번
**확인** : 페이더를 움직이면 `채널값 및 필터 출력` 값이 따라 움직임

```
1) MIDI 연결
2) 뱅크 선택       (최대 8개 · 뱅크마다 다른 조합)
3) 채널마다 움직일 모션 ID 고르기
4) MIDI 뱅크 설정 저장
```

| 버튼 | 무엇 |
|---|---|
| `MIDI 연결` · `연결 해제` | 조작기 붙이기·떼기 |
| `상태 새로고침` | 지금 상태 다시 읽기 |
| `실시간 값 초기화` | 화면에 남은 값 지우기 |
| `뱅크 추가` · `뱅크 삭제` | 조합 묶음 만들기·지우기 |
| `MIDI 뱅크 설정 저장` | 설정을 파일에 적기 |
| `파일에서 불러오기` | 저장해 둔 설정 가져오기 |

**필터** : 0~13단계 · 높일수록 손떨림이 덜 묻지만 반응이 느려짐

📷 *(캡처: MIDI 입력 설정 · 뱅크와 채널 표)*

### 5-1. 녹화

```
1) 초기 위치 이동
2) 녹화 대상 Motion ID 고르기
3) ● 녹화        →  MIDI 로 움직이기
4) ■ 녹화·재생 정지
5) ▶ 레이어 재생  →  들어보기
```

| 버튼 | 무엇 |
|---|---|
| `초기 위치 이동` | 모터를 시작 자리로 |
| `● 녹화` | 새로 녹화 |
| `● 추가 녹화` | 있는 것 위에 덧입히기 |
| `■ 녹화·재생 정지` | 멈추기 |
| `▶ 레이어 재생` | 녹화한 것 듣기 |

📷 *(캡처: 스튜디오 · 녹화 버튼과 그래프)*

### 5-2. 다듬기

**위치** : `레이어 관리 열기`
**개념** : 레이어 = 겹 · 여러 겹을 만들어 합침
**편집 뒤** : `작업본 반영` → `저장`

| 버튼 | 무엇 |
|---|---|
| `새 레이어 생성` · `선택 레이어 복사` | 겹 만들기 |
| `레이어 합치기` | 여러 겹을 하나로 |
| `레이어 편집` | 점 단위로 고치기 |
| `잠금` | 실수로 못 고치게 |
| `삭제` | 겹 지우기 |

### 5-3. 실행으로 보내기

**버튼** : `모션 파일 등록`
**안 누르면** : `모션 실행` 화면에 안 나타남

### 5-4. 편집 도구 모음

*(내용 보완 필요 · 각 도구가 무엇을 하는지)*

## 6. 시험 운전

**위치** : `실행·시험` → `동작 테스트`
**언제** : 모션을 돌리기 전 · 축 하나씩 확인

### 순서

```
1) 1. 시험 축 선택
2) 2. 서보 준비    →  서보 켜기  (오류 있으면 오류 초기화)
3) 4. 동작 명령    →  - 방향 / + 방향 고르고 동작 실행
4) 5. 결과 확인    →  요청값과 실제값 비교
```

| 버튼 | 무엇 |
|---|---|
| `서보 켜기` · `서보 끄기` | 힘 넣기·빼기 |
| `오류 초기화` | 서보 오류 지우기 |
| `- 방향` · `+ 방향` | 움직일 방향 |
| `동작 실행` | 움직이기 |
| `경계 위치로 복귀` | 범위 끝으로 되돌리기 |
| `모터 동작 정지` | 언제든 멈추기 |

📷 *(캡처: 동작 테스트 · 축 선택과 동작 명령 부분)*

## 7. 모션 실행

**위치** : `실행·시험` → `모션 실행`

### 순서

```
1) 1. 실행할 모션  →  파일 고르고 「재생 등록」
2) 2. 실행        →  실행 준비 검사  →  초기 위치 이동  →  1회 시작 / 연속 시작
3) 3. 진행        →  회차·단계·진행률 보기
```

### 7-1. 모션 고르기

| 버튼 | 무엇 |
|---|---|
| `재생 등록` | 이 모션을 돌릴 것으로 지정 |
| `재생 등록 해제` | 등록 취소 |
| `스튜디오로` | 그 모션을 스튜디오에서 열기 |
| `내 PC로 저장` | 파일 내려받기 |
| `삭제` | 모션 파일 삭제 |

### 7-4. 파일 주고받기 (PC 사이)

**오갈 수 있는 것** : **모션 파일 하나뿐**

**순서** :

```
1) 보낼 PC :  모션 실행 → 파일 선택 → 「내 PC로 저장」

```

**주의** :

| 못 하는 것 | 이유 |
|---|---|
| 모터축 설정 옮기기 | 그 PC 의 배선에 매인 값 · 옮기면 꼬임 · **거부됨** |
| 모션축 설정 옮기기 | 위와 같음 · **거부됨** |
| 프로젝트 통째로 옮기기 | 그런 기능 없음 · 프로젝트는 각 PC 에서 만듦 |
| 모션축 설정 없는 프로젝트에 넣기 | **거부됨** · 모션축 설정을 먼저 만들 것 |

**MIDI 설정** : `파일에서 불러오기` 는 **그 PC 에 저장된** 뱅크 파일을 다시 읽는 것 · PC 사이 전달 아님

📷 *(캡처: 스케줄 추가 창)*

### 어떻게 도는가

**판단 기준** : 「시각을 지나갔나」가 아니라 **「지금 구간 안인가」**
**점검 주기** : 1분마다
**구간 안인데 멈춰 있으면** : 시작
**구간 밖인데 돌고 있으면** : 현재 회차를 끝내고 정지

이 방식이라 **놓치는 일이 없습니다.**

| 일어난 일 | 결과 |
|---|---|
| 개장 시각에 PC 가 꺼져 있었음 | 켜면 1분 안에 시작 (구간 안이므로) |
| 한낮에 재부팅 | 다시 뜨면 이어서 시작 |
| 정전으로 멈춤 | 복구되면 시작 |
| 종료 시각을 넘겨 재시작 | 안 시작함 (구간 밖이므로) |

### 시각 정하기

**자정 넘기기** : 종료가 시작보다 이르면 다음 날로 봄 · `23:00 ~ 01:00` = 그날 23시 ~ 다음 날 1시
**여러 개 겹칠 때** : **먼저 시작한** 스케줄을 따름
**끄기** : 스케줄마다 켜고 끌 수 있음 · 지우지 않아도 됨

### 반복

| 종류 | 무엇 |
|---|---|
| 매일 | 날마다 |
| 요일 지정 | 고른 요일에만 |
| 1회 | 정한 날짜 하루만 |

**1회 날짜** : 이 PC 기준 오늘이 기본값

### 여러 대를 묶었을 때

**판단하는 PC** : 마스터 한 대만
**슬레이브** : 스케줄이 아무 일도 안 함 · 마스터가 보내는 그룹 실행만 따름
**설정하는 곳** : 마스터에서만 · 슬레이브는 화면이 잠김

### 알아둘 것

**PC 시각** : 화면 위쪽 `🕒 PC 시각` 에 시간대가 같이 표시 · 설치한 나라와 다르면 엉뚱한 시각에 돎
**정지해도 다시 시작** : 스케줄 모드에서는 정지해도 최대 1분 뒤 재시작
**계속 멈추려면** : 수동 모드로 **먼저** 바꾸고 → 정지
**딱지 확인** : 화면 맨 위 딱지가 🟢 면 정상 · 🔴 면 시작이 거부되는 중

```
1) 원인 해결
2) 프로그램 재시작        (화면 맨 위 또는 시스템 정보)
3) 딱지가 🟢 인지 확인
```

**주의** : 긴급 정지는 **재시작 전까지 안 풀립니다**

## 12. 문제가 생겼을 때

### 자주 나오는 것

| 증상 | 원인 | 할 일 |
|---|---|---|
| 검색해도 모터가 안 나옴 | 전원·랜선 | 서보 전원과 EtherCAT 랜선 확인 |
| 설정을 바꿨는데 모터가 그대로 | 2단계 안 누름 | `장비에 적용 · 모터 재시작` |
| `설정 저장` 이 회색 | 고친 게 없음 | 값을 고치면 켜짐 |
| 모션이 시작 안 됨 | 서보 꺼짐·오류 | `동작 테스트` → `서보 켜기` · `오류 초기화` |
| 시각이 됐는데 안 돎 | 수동 모드 | `📅 모션 스케줄` → 스케줄 모드 |
| 딱지가 빨강 | 시작이 거부됨 | 딱지에 마우스 올려 이유 확인 |
| 스케줄이 엉뚱한 시각에 돎 | 시간대 다름 | `🕒 PC 시각` 확인 · [README](../README.md) |

### 연동 문제

| 증상 | 할 일 |
|---|---|
| 상대 PC 가 「통신 단절」 | 그 PC 전원 · 그룹 ID·Domain ID 확인 |
| 빨간 오류 창 | `PC 연동` → `그룹 오류 확인` · 아무 PC 한 대에서만 |
| 버전이 서로 다름 | 뒤처진 PC 에서 `bash src/motion_web/install.sh` |
| 서보 알람 | 알람이 난 그 PC 에서 해제 |

### 멈춘 뒤 다시 돌리기

| 어떻게 멈췄나 | 저절로 돌아오나 | 할 일 |
|---|---|---|
| `즉시 정지` · `현재 회차 후 정지` | 예 · 스케줄 모드면 1분 안에 | 그냥 두기 |
| 수동 모드로 바꿈 | 아니오 | 스케줄 모드로 |
| 그룹 오류 | 아니오 | `그룹 오류 확인` |
| 긴급 정지 | 아니오 | 프로그램 전체 재시작 |
