# 사용법

화면을 열고, 프로젝트를 만들고, 모터를 등록하고, 모션을 만들어 실행하기까지
**하는 순서대로** 적었습니다.

설치는 [README](../README.md) 를 보세요. 이 글은 설치가 끝난 PC 기준입니다.

## 1. 시작하기

### 화면 열기

```text
http://localhost:8000
```

다른 PC 에서 볼 때는 `localhost` 대신 그 PC 의 주소를 넣습니다. (예: `http://172.16.21.10:8000`)

### 화면 구성

위쪽에 **묶음 4개**, 그 아래에 **탭**이 있습니다.

| 묶음 | 탭 |
|---|---|
| **운영** | 실시간 모니터링 · 서보 에러 관리 · 로그 · PC 성능 · 터미널 |
| **프로젝트·장비** | 시스템 정보 · 프로젝트 관리 · 모터 관리 |
| **모션 제작** | 모션축 설정 · MIDI 입력 설정 · 모션 스튜디오 |
| **실행·시험** | 동작 테스트 · 모션 실행 · PC 연동 설정 |

맨 위 오른쪽에는 **`📅 모션 스케줄`** 버튼과 **스케줄러 상태 딱지**가 있습니다.

📷 *(캡처: 화면 맨 위 · 묶음 4개와 탭이 보이게)*

### 딱지 색으로 보는 상태

| 색 | 뜻 |
|---|---|
| 🟢 초록 | 정상 · 시각이 되면 돕니다 |
| 🟡 노랑 | 돌아야 하는데 못 돌고 있습니다 |
| 🔴 빨강 | 계속 못 돌고 있습니다 |
| ⚫ 회색 | 스케줄이 손대지 않는 상태 |

노랑·빨강이면 딱지에 마우스를 올려 이유를 봅니다.

## 2. 프로젝트 만들기

> **`프로젝트·장비`** → **`프로젝트 관리`**

프로젝트는 **모터 설정 · 모션 파일 · 스케줄을 담는 통**입니다. 현장 하나에 하나씩 만듭니다.

### 2-1. 만들기

**`새 프로젝트`** → 이름 입력

### 2-2. 고르기

왼쪽 목록에서 프로젝트를 누르면 선택됩니다.

> 프로젝트 바꾸기는 **`시스템 정보`** 화면에서만 됩니다. 다른 화면에서는 잠겨 있습니다.

📷 *(캡처: 프로젝트 관리 · 목록과 새 프로젝트 버튼)*

### 그 밖의 버튼

| 버튼 | 무엇 |
|---|---|
| `프로젝트 목록 갱신` | 목록을 다시 읽습니다 |
| `내 PC에서 가져오기` | 다른 PC 에서 받은 프로젝트를 올립니다 |
| `현재 프로젝트 삭제` | 휴지통으로 보냅니다 |
| `메모 저장` | 현장 메모를 남깁니다 |

---

## 3. 모터 등록하기

> **`프로젝트·장비`** → **`모터 관리`**

### 3-1. 찾기

`1. 장비 검색` 에서 **`전체 모터 검색`**

| 버튼 | 언제 |
|---|---|
| `전체 모터 검색` | 보통 이것 |
| `AC Servo 검색` | AC 서보만 다시 찾을 때 |
| `Dynamixel 검색` | 다이나믹셀만 다시 찾을 때 |

📷 *(캡처: 검색 결과가 나온 표)*

> 아무것도 안 나오면 → [11장](#11-문제가-생겼을-때)

### 3-2. 쓸 축 고르기

`2. 검색 결과 확인 및 축 편집` 표에서 줄을 누르고:

| 버튼 | 무엇 |
|---|---|
| **`선택 축 추가`** | 이 프로젝트에서 쓰겠다고 등록 |
| `모델·운전 프로필 설정` | 모터 종류·운전값 지정 |
| `선택 축 사용상태 변경` | 잠시 안 쓰게 |
| `축 번호 정렬` | 번호를 차례로 |
| `선택 축 삭제` | 등록 취소 |

### 3-3. 값 고치기 (필요할 때)

`상세 설정 표` 탭에서 값을 고칩니다. 고칠 수 있는 항목은 정해져 있고, 나머지는 글자로만 보입니다.

| 고칠 수 있는 것 | |
|---|---|
| `controller_index`, `name` | 축 번호·이름 |
| `lower`, `upper` | 움직일 수 있는 최소·최대 위치 |
| `speed`, `acceleration`, `deceleration` | 속도·가감속 |
| `profile_velocity` 등 | 운전 프로필 |

### 3-4. 저장하고 장비에 넣기

`3. 저장하고 장비에 적용` 에서 **왼쪽부터**:

| | 버튼 | 무엇이 되나 |
|---|---|---|
| 1단계 | **`설정 저장`** | 설정 파일에 적힙니다 · **모터는 아직 그대로** |
| 2단계 | **`장비에 적용 · 모터 재시작`** | 실제 모터에 들어갑니다 · **모터가 잠깐 멈췄다 켜집니다** |

> **2단계를 안 누르면 모터는 안 바뀝니다.** 파일만 바뀝니다.

📷 *(캡처: 3. 저장하고 장비에 적용 · 버튼 두 개)*

**확인** — 표의 축이 정상으로 보이고, 위쪽 `현재 실행 장비 상태` 가 맞으면 됩니다.

## 4. 모션축 잇기

> **`모션 제작`** → **`모션축 설정`**

모터는 `축 0`, `축 1` 처럼 번호로 부릅니다. 모션은 `1-1`, `1-2` 처럼 **모션 ID** 로 부릅니다.
**둘을 맺어 주는 자리**입니다.

### 4-1. 설정 파일 고르기

`1. 설정 파일 선택` 에서 목록에서 고르거나 **`새 매칭 작성`**

### 4-2. 이어 주기

`2. 모션축 편집` 에서:

| 버튼 | 무엇 |
|---|---|
| **`모터축 행 자동 생성`** | 등록된 모터 수만큼 줄을 만듭니다 (보통 이것부터) |
| `모션 ID 추가` | 줄을 하나씩 추가 |
| `모션 ID 반영` | 스튜디오에서 쓰는 이름을 가져옵니다 |

각 줄에 **모션 ID ↔ 모터축** 을 맞추고, 필요하면 변환값(범위·방향)을 넣습니다.

📷 *(캡처: 2. 모션축 편집 표 · 모션 ID 와 모터축이 맺어진 상태)*

### 4-3. 저장

`3. 검증·미리보기·저장` 에서 **`검증·미리보기·저장`**

| 버튼 | 무엇 |
|---|---|
| `저장된 내용으로 되돌리기` | 고친 것 취소 |
| `현재 설정 파일 삭제` | 이 매칭 파일 삭제 |

**확인** — `미사용 모터축` 에 남은 축이 없으면 다 이어진 것입니다.

## 5. 모션 만들기

> **`모션 제작`** → **`모션 스튜디오`**

### 5-1. 준비

1. **`초기 위치 이동`** — 모터를 시작 자리로 보냅니다
2. `녹화 대상 Motion ID` 에서 녹화할 축을 고릅니다

### 5-2. 녹화

| 버튼 | 무엇 |
|---|---|
| **`● 녹화`** | 새로 녹화 |
| `● 추가 녹화` | 이미 있는 것 위에 덧입히기 |
| **`■ 녹화·재생 정지`** | 멈추기 |
| `▶ 레이어 재생` | 녹화한 것 들어보기 |

MIDI 로 움직이며 녹화합니다. (MIDI 설정은 `MIDI 입력 설정` 탭)

📷 *(캡처: 스튜디오 · 녹화 버튼과 그래프)*

### 5-3. 다듬기

**`레이어 관리 열기`** 에서 여러 겹(레이어)을 만들고 합칩니다.

| 버튼 | 무엇 |
|---|---|
| `새 레이어 생성` · `선택 레이어 복사` | 겹 만들기 |
| `레이어 합치기` | 여러 겹을 하나로 |
| `레이어 편집` | 점 단위로 고치기 |
| `잠금` | 실수로 못 고치게 |

**레이어 편집** 안에서 점을 찍고 옮깁니다 — `포인트 추가` · `포인트 삭제` · `시간 이동` · `모션값 배율` 등. 고친 뒤 **`작업본 반영`** → **`저장`**.

### 5-4. 실행으로 보내기

**`모션 파일 등록`** — 이걸 눌러야 `모션 실행` 화면에 나타납니다.

## 6. 시험 운전

> **`실행·시험`** → **`동작 테스트`**

모션을 돌리기 전에 **축 하나씩** 움직여 봅니다.

| | 하는 일 |
|---|---|
| `1. 시험 축 선택` | 움직일 축 고르기 |
| `2. 서보 준비` | **`서보 켜기`** · 오류가 있으면 `오류 초기화` |
| `4. 동작 명령` | `- 방향` / `+ 방향` 고르고 **`동작 실행`** |
| | `경계 위치로 복귀` — 범위 끝으로 되돌리기 |
| `5. 결과 확인` | 요청한 값과 실제 값 비교 |

> **`모터 동작 정지`** 는 언제든 누를 수 있습니다.

📷 *(캡처: 동작 테스트 · 축 선택과 동작 명령 부분)*

## 7. 모션 실행

> **`실행·시험`** → **`모션 실행`**

### 7-1. 모션 고르기

`1. 실행할 모션` 에서 파일을 고르고 **`재생 등록`**

| 버튼 | 무엇 |
|---|---|
| `재생 등록 해제` | 등록 취소 |
| `스튜디오로` | 그 모션을 스튜디오에서 열기 |
| `내 PC로 저장` | 파일 내려받기 |

### 7-2. 실행

`2. 실행` 에서 **위에서부터**:

| 버튼 | 무엇 |
|---|---|
| **`실행 준비 검사`** | 돌려도 되는지 먼저 확인 |
| **`초기 위치 이동`** | 시작 자리로 |
| **`1회 시작`** | 한 번만 |
| **`연속 시작`** | 계속 반복 |
| `현재 회차 후 정지` | 지금 회차 끝나고 멈춤 |
| **`즉시 정지`** | 바로 멈춤 |

📷 *(캡처: 2. 실행 · 버튼 줄)*

### 7-3. 보기

`3. 진행` 에서 회차·단계·진행률을 봅니다.

## 8. 여러 대 묶기

> **`실행·시험`** → **`PC 연동 설정`**

여러 PC 를 묶어 **같은 시각에 함께** 돌립니다. 한 대만 쓰면 이 장은 건너뜁니다.

### 8-1. 각 PC 에서 설정

| 항목 | 규칙 | 예 (1번 / 2번) |
|---|---|---|
| 연동 사용 | 모두 `사용` | |
| 이 PC ID | PC 마다 **다르게** | `pc-a` / `pc-b` |
| 표시 이름 | PC 마다 **다르게** | `PC A` / `PC B` |
| 그룹 ID | 묶을 PC 끼리 **같게** | `stage-a` / `stage-a` |
| DDS Domain ID | 묶을 PC 끼리 **같게** | `21` / `21` |
| 역할 | **한 대만** 마스터 | 마스터 / 슬레이브 |

**`설정 저장·연동 재시작`** 을 누릅니다.

### 8-2. 명단 확정

`2. 그룹 참가 PC` 표에 상대 PC 가 보이면 **`현재 접속 PC로 명단 확정`**

📷 *(캡처: PC 연동 · 세 대가 「정상」으로 보이는 표)*

**확인** — 모든 PC 가 🟢 `정상`, `버전 (Git)` 이 서로 같아야 합니다.

> 버전이 다르면 그 PC 만 갱신이 안 된 것입니다. 터미널에서 `bash src/motion_web/install.sh`

### 8-3. 함께 돌리기

시작은 **마스터에서만** 됩니다. 정지는 아무 PC 에서나 됩니다.

## 9. 스케줄 걸기

> 화면 맨 위 **`📅 모션 스케줄`**

시각이 되면 알아서 시작하고, 끝나면 멈춥니다.

### 9-1. 실행 관리 고르기

| | 무엇 |
|---|---|
| **스케줄 모드** | 시각에 맞춰 시작·정지합니다 |
| **수동 모드** | 스케줄이 아무것도 안 합니다 (정비·시험 중) |

### 9-2. 스케줄 추가

**`+ 신규 스케줄 추가`** 에서:

| 항목 | |
|---|---|
| 스케줄 이름 | 알아볼 이름 |
| 시작 시각 / 종료 시각 | 현지 시각 기준 |
| 반복 | 매일 · 요일 지정 · 1회 |

📷 *(캡처: 스케줄 추가 창)*

### 9-3. 알아둘 것

- 화면 위쪽 **`🕒 PC 시각`** 에 시간대가 같이 나옵니다. **설치한 나라와 다르면 스케줄이 엉뚱한 시각에 돕니다.**
- **스케줄 모드에서는 정지를 눌러도 최대 1분 뒤 다시 시작합니다.**
  계속 멈춰 두려면 **수동 모드로 먼저 바꾸고** 정지하세요.

## 10. 운영 중 보기

> **`운영`** 묶음

| 탭 | 언제 봅니다 |
|---|---|
| **실시간 모니터링** | 축별 위치·속도·토크를 실시간으로 |
| **서보 에러 관리** | 지금 난 에러 · 에러별 등급 설정 |
| **로그** | 지나간 일 (모터 에러 · 초기 위치 이동 · 모션 시작) |
| PC 성능 | CPU·메모리 |
| 터미널 | 갱신 명령을 치는 곳 |

### 실시간 모니터링

1. 위쪽에서 모터 종류를 고릅니다 (`전체` · `AC 서보` · `다이나믹셀` …)
2. 표에서 모터 줄을 누릅니다
3. 아래 탭에서 자세히 봅니다 — `기본 정보` · `연결·통신` · `운전·오류` · `실시간값` · `사양·설정`

> 안 볼 때는 **`모니터링 끄기`** 로 꺼 두면 PC 가 가벼워집니다.

📷 *(캡처: 실시간 모니터링 · 표와 상세 탭)*

### 로그

`전체` · `모터 에러` · `초기 위치 이동` · `모션 시작` 으로 걸러 봅니다.

## 11. 문제가 생겼을 때

### 자주 나오는 것

| 증상 | 원인 | 할 일 |
|---|---|---|
| 검색해도 모터가 안 나옴 | 전원·랜선 | 서보 전원과 EtherCAT 랜선 확인 |
| 설정을 바꿨는데 모터가 그대로 | 2단계를 안 누름 | `장비에 적용 · 모터 재시작` |
| `설정 저장` 이 회색 | 고친 게 없음 | 값을 고치면 켜집니다 |
| 모션이 시작이 안 됨 | 서보 꺼짐·오류 | `동작 테스트` 에서 `서보 켜기` · `오류 초기화` |
| 시각이 됐는데 안 돎 | 수동 모드 | `📅 모션 스케줄` → 스케줄 모드 |
| 딱지가 빨강 | 시작이 거부됨 | 딱지에 마우스를 올려 이유 확인 |
| 스케줄이 엉뚱한 시각에 돎 | 시간대가 다름 | `🕒 PC 시각` 확인 · [README](../README.md) 시간대 |

### 연동에서 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| 상대 PC 가 「통신 단절」 | 그 PC 가 켜져 있는지 · 그룹 ID·Domain ID 가 같은지 |
| 빨간 오류 창이 뜸 | `PC 연동` → **`그룹 오류 확인`** · **아무 PC 한 대에서만** 누르면 전부 풀립니다 |
| 버전이 서로 다름 | 뒤처진 PC 에서 `bash src/motion_web/install.sh` |
| 서보 알람이 뜸 | **알람이 난 그 PC 에서** 풀어야 합니다 |

### 멈춘 뒤 다시 돌리기

| 어떻게 멈췄나 | 저절로 돌아오나 |
|---|---|
| `즉시 정지` / `현재 회차 후 정지` | **예** · 스케줄 모드면 1분 안에 |
| 수동 모드로 바꿈 | 아니오 · 스케줄 모드로 되돌리기 |
| 그룹 오류 | 아니오 · `그룹 오류 확인` |
| **긴급 정지** | 아니오 · **프로그램 전체 재시작** |
