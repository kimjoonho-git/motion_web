모션 파일을 선택하고 Motion ID를 반영하세요
값 기준 Motion ID는 사용자가 정하는 모션축 번호입니다. 양의 정수-양의 정수 형식으로 입력합니다(예: 1-1, 2-3). 모션값·Min/Max·초기위치·Offset은 모션/출력축 deg 기준입니다. 기준점과 최종 모터 목표는 모터축 deg 기준입니다. Min/Max 초과 데이터는 실행을 막지 않고 경계값으로 제한해 명령합니다.
계산 흐름 제한 모션값 = 모션값을 Min ~ Max 범위로 제한 출력축 값 = (제한 모션값 + Offset) × Scale × 반전부호 모터축 목표 = 기준점 + (출력축 값 × 감속비)

필터 출력은 2차 저역통과 필터만 적용한 값이고, 최종 출력은 반전과 Min/Max(%)까지 모두 적용한 값입니다. 모션값은 최종 출력 0~16383을 해당 Motion ID의 Min~Max 각도로 변환한 값입니다. Max가 100%를 넘으면 Min은 0%로 자동 고정되며 최종 출력은 항상 0~16383으로 제한됩니다.
