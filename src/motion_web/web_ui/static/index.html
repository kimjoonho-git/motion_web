모션 파일을 선택하고 Motion ID를 반영하세요
값 기준 모션값·Min/Max·초기위치·Offset은 모션/출력축 deg 기준입니다. 기준점과 최종 모터 목표는 모터축 deg 기준입니다. Min/Max 초과 데이터는 실행을 막지 않고 경계값으로 제한해 명령합니다.
계산 흐름 제한 모션값 = 모션값을 Min ~ Max 범위로 제한 출력축 값 = (제한 모션값 + Offset) × Scale × 반전부호 모터축 목표 = 기준점 + (출력축 값 × 감속비)
