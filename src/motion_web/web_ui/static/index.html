값 기준 모션 ID는 사용자가 정하는 모션축 번호입니다. 양의 정수-양의 정수 형식으로 입력합니다(예: 1-1, 2-3). 모션값·최솟값/최댓값·초기 위치·보정값은 모션/출력축 deg 기준입니다. 기준점과 최종 모터 목표는 모터축 deg 기준입니다. 기준점 사용을 해제하면 계산 기준점은 0 deg가 됩니다. 최솟값/최댓값 초과 데이터는 실행을 막지 않고 경계값으로 제한해 명령합니다.
계산 흐름 제한 모션값 = 모션값을 최솟값~최댓값 범위로 제한 출력축 값 = (제한 모션값 + 보정값) × 배율 × 반전 부호 모터축 목표 = 기준점 + (출력축 값 × 감속비)
